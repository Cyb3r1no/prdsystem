قبل ما نقترح الحل

خلّنا نفهم المشروع صح

جاوب بطريقتك وبعيد عن المصطلحات التقنية. هدفنا نفهم المشكلة، طريقة العمل الحالية والنتيجة اللي تبيها قبل ما نبني الـ PRD أو نقترح الحل.

ما نبي منك حل تقني

قل لنا وش يصير اليوم، وش اللي يضايقكم، ووش النتيجة المطلوبة. اختيار التقنية والحل مسؤوليتنا بعد التحليل.

وش يصير بعد الإرسال؟
  1. نراجع الرد ونحدد الفجوات والأسئلة المهمة.
  2. نناقش معكم النقاط اللي تحتاج توضيح فقط.
  3. نحدد الحلول والـ MVP المناسب.
  4. نبني PRD مبدئي ونراجعه قبل أي تنفيذ.
تنبيه مهم

لا تضع كلمات مرور، API Keys، بيانات بطاقات أو أسرار تشغيلية. أسماء الأنظمة وطريقة العمل تكفينا في هذه المرحلة.
